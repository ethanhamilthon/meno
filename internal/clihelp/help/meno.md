# meno

Use `meno <command>`. Run `meno <command> --help` for details.

Commands: mcp, tasks, ask, goal, view, models, daemon, sessions, send, tail.
Arguments for API commands can be JSON objects or key=value pairs. Add --json for structured output.

Exit codes: 0 success, 1 error, 2 usage, 3 forbidden by mode, 124 wait timeout.
