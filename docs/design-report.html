meno · design decisions report

A Go TUI agent. One tool: a JavaScript REPL (js). Design: tui.pen, 16 screens.

1. Architecture

LayerPackageResponsibility
Entrycmd/menotcell screen, App construction, event loop startup
UIinternal/uiTheme, canvas, transcript rows, JS highlighting, primitives
Applicationinternal/appState, keys, modals, commands, turns
Agentinternal/agentRequest loop, sessions, compaction, synchronized log
LLMinternal/llmResponses and Chat Completions protocols, SSE, model catalog
JS VMinternal/jsvmgoja, fs, sh, print, timeout, cancellation
MCPinternal/mcpJSON-RPC over stdio, server manager
Storageinternal/config, internal/storeJSON files: settings, providers, prompts, skills, servers

Guideline: files stay around 200 lines. Package boundaries keep agent internals out of the UI and tcell out of the agent.

2. Key decisions

DecisionReason
JSON files instead of SQLiteNo CGO, one static binary, human-readable sessions.
Responses and Chat CompletionsResponses supports OpenAI reasoning models; Chat supports compatible local and third-party APIs.
SSE streamingText and thinking appear as they are generated.
MCP over stdio JSON-RPCA standard interface for external tools, exposed in JS as mcp.<server>.*.
goja for JSPure Go, with async/await and Promise support. Top-level await is wrapped in an async IIFE.
Direct filesystem and shell operationsRelative paths and shell commands use the project working directory; absolute paths and external symlinks work normally.
SafeLog with RWMutexThe agent writes sessions from a goroutine while the UI reads. Tests run with -race.
UI event loopKeys and agent events share one channel; only the event loop draws.

3. Design rules (from tui.pen)

  • One font size: the terminal grid. No borders or rounded corners.
  • Rows use background colors: bg-user, bg-js-done, bg-js-run.
  • Glyphs: ✻ thinking, ◆ agent response, ◇ intermediate step, ▸ selection, ●/○ status.
  • Modals use bg-popup; selected rows use bg-popup-sel.
  • Visual mode: the selected turn uses bg-select, with y yank · r run in the status hint.

5. Edge cases

  • Duplicate provider, MCP server, and prompt names are rejected with a toast message.
  • Invalid prompt names (outside [a-z0-9-] or longer than 40 characters) are rejected.
  • MCP environment: comma-separated KEY=VALUE; missing = is an error.
  • A model without a configured provider cannot start a turn; a toast explains the issue.
  • Ctrl+C cancels a turn through its context; the session is marked [aborted].
  • Empty modal lists show “nothing here”.
  • Searching a modal resets selection to the top.
  • An empty session shows the welcome screen instead of a transcript.
  • # autocomplete closes on Space or Esc, preserving entered text.

7. Known limitations

  • The cancellation e2e test checks the Running flag rather than session contents.
  • Visual comparisons use text and colors from tui.pen, not pixel-level screenshots.
  • Provider/model selection has not been checked against a live API.
