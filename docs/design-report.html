meno · отчёт о дизайн-решениях

TUI-агент на Go. Один инструмент — JavaScript REPL (js). Дизайн: tui.pen, 16 экранов.

1. Архитектура

СлойПакетОтветственность
Entrycmd/menotcell screen, сборка App, запуск цикла
UIinternal/uiтема, холст, строки транскрипта, подсветка JS, примитивы
Приложениеinternal/appсостояние, клавиши, модалки, команды, ход (turn)
Агентinternal/agentцикл запросов, сессии, компактация, безопасный лог
LLMinternal/llmдва протокола (Responses и Chat Completions), SSE, каталог моделей
JS VMinternal/jsvmgoja, fs, sh, print, gate auto/ask, таймаут, abort
MCPinternal/mcpJSON-RPC по stdio, менеджер серверов
Хранилищеinternal/config, internal/storeJSON-файлы: настройки, провайдеры, промпты, скиллы, серверы

Ограничение: файлы до ~200 строк. Пакеты разделены так, чтобы UI не знал о деталях агента, а агент — о tcell.

2. Ключевые решения

РешениеПочему
JSON-файлы вместо SQLiteНет CGO, один статический бинарник, сессии читаемы руками.
Два протокола: Responses и Chat CompletionsResponses для OpenAI-моделей с reasoning, Chat для совместимых локальных и сторонних API.
SSE-стримингТекст и thinking появляются по мере генерации.
MCP через stdio JSON-RPCСтандартный способ подключения внешних инструментов; инструменты доступны из JS как mcp.<server>.*.
goja для JSЧистый Go, поддерживает async/await и Promise. Top-level await оборачивается в async IIFE.
Gate auto / askВ режиме ask каждое действие (запись, sh) спрашивает пользователя через канал approval.
Пути только внутри корня проектаЗащита от записи за пределы рабочей папки.
SafeLog с RWMutexАгент пишет в сессию из горутины, UI читает. Гонка найдена и устранена, тесты идут с -race.
Событийный цикл в UIКлючи, агентские события и ответы approval идут в один канал; рисование только из цикла.

3. Дизайн-правила (из tui.pen)

  • Один размер шрифта — терминальная сетка. Без рамок и скруглений.
  • Строки выделяются фоном: bg-user, bg-js-done, bg-js-run.
  • Глифы: ✻ мысль, ◆ ответ агента, ◇ промежуточный шаг, ▸ выбор, ●/○ статус.
  • Модалки на bg-popup, выбранная строка на bg-popup-sel.
  • Визуальный режим: выбранный ход на bg-select, в статусе подсказка y yank · r run.

5. Edge-кейсы

  • Дубликаты имён провайдеров, MCP-серверов и промптов отклоняются с сообщением в тосте.
  • Невалидное имя промпта (не [a-z0-9-], длина > 40) отклоняется.
  • Env MCP: KEY=VALUE через запятую; без = — ошибка.
  • Модель без настроенного провайдера: ход не стартует, показывается тост.
  • Ctrl+C прерывает ход через context; сессия помечается [aborted].
  • Пустые списки в модалках показывают «nothing here».
  • Поиск в модалках сбрасывает выбор в начало списка.
  • Пустая сессия показывает welcome вместо транскрипта.
  • Автокомплит # закрывается при пробеле и при Esc, сохраняя введённый текст.

6. Тесты

ПакетЧто проверяется
config, llm, jsvm, mcp, agentМодульные тесты; jsvm — timeout и abort; mcp — fake stdio сервер на Python.
uiПеренос строк, ширина с кириллицей, подсветка JS, код-блоки.
appРендер на SimulationScreen, модалки, автокомплит, визуальный режим, валидация форм.
app e2eПолный ход с mock LLM: текст → JS tool → ответ → сохранение сессии; abort; отсутствующий провайдер.

Все тесты запускаются с go test -race ./....

7. Известные ограничения

  • E2E-тест abort проверяет только сброс Running, а не содержимое сессии.
  • Визуальное сравнение с дизайном сделано по тексту и цветам из tui.pen, не по пиксельному снимку.
  • Выбор провайдера/модели не проверен против живого API.
